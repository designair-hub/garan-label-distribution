# GARAN Label for WooCommerce - releases

Public release channel for the **GARAN Label for WooCommerce** plugin.
The plugin checks this repository for new releases and offers them as
regular updates in WordPress (*Plugins* / *Dashboard → Updates*).

Releases are published automatically from the (private) source repository -
do not commit here by hand.

Manual install: download `garan-label-for-woocommerce.zip` from the latest
[release](../../releases/latest) and upload it via *Plugins → Add New → Upload Plugin*.
